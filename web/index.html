Como usar: copie o comando e troque os campos <ASSIM> pelos valores do ambiente. Para um parâmetro opcional, acrescente &nome=valor na URL (listas separadas por vírgula). Valor inválido não executa nada: o terminal mostra o erro. Rode como Administrador (Windows) ou com sudo (Linux).
